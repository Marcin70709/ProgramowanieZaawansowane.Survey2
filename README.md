Survey App — ASP.NET Core MVC

A web application for creating surveys, collecting votes, and managing users with role-based access control.

Features

User registration and login

Role-based authorization: Admin, Ankieter, Respondent

Survey creation and management

Voting and survey results

Admin panel for managing users and assigning roles

Entity Framework Core database integration

Technologies

C#

ASP.NET Core MVC

ASP.NET Core Identity

Entity Framework Core

Microsoft SQL Server / LocalDB

Razor Views

Bootstrap

Git and GitHub

Getting Started

Requirements

.NET SDK 8

SQL Server LocalDB

Visual Studio or Visual Studio Code

Run locally

Clone the repository.

Open the project folder in a terminal.

Restore dependencies:

dotnet restore

Configure the database connection in appsettings.json.

Apply database migrations if needed.

Start the application:

dotnet run

Open the local URL displayed in the terminal.
